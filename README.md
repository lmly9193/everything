# Chrome Extension for Everything

This Chrome extension allows you to select any text on a web page and instantly search for it using the [Everything](https://www.voidtools.com/) desktop search tool.

## Features
- Instantly shows a search icon when you select text on any web page. Click the icon to search the selected text with Everything.
- Context menu support: right-click selected text and trigger an Everything search directly from the menu.
- Seamless integration with Everything's URL protocol for fast and accurate local file searches.

## Installation & Setup
### 1. Install Everything
- Download and install the latest version of [Everything](https://www.voidtools.com/).

### 2. Configure Everything
- Launch Everything.
- Go to "Tools" → "Options".
- In the "General" tab, check the "URL protocol" option.
- Click "OK" to save the settings.

### 3. Install this Extension
- Install from the Chrome Web Store, or load it manually as an unpacked extension.

## Usage
1. Select any text on a web page.
2. A search icon will appear—click it to launch Everything and search for the selected text.
3. Alternatively, right-click the selected text and choose "Search on PC for 'xxx'" from the context menu.

## Notes
- Make sure Everything is properly installed and running in the background before using the extension.
- This extension only triggers searches; results are displayed in the Everything application.
